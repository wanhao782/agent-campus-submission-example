# 复盘

最难的问题是资料冲突时如何结束。模型曾读到两个期限、完成补查并说明缺口，最后仍选择了 `answer`。为此将 `answered` 的约束收紧到有已读引用且没有待解决缺口。错误会交回模型，下一步仍由它决定。

真实 Trace 也暴露了“提交期限”这一通用标签的歧义。它让住宿发票追问召回了日常费用制度。改用更贴近条款适用对象的标签后，使用原问题复跑。用相同问题切换资料版本可以把模型的语义决策与固定答案区分开来，也更容易定位召回问题。

实际用时约 10 分钟，从初始化 Git 到完成本地验收，依据工作区时间估算。GitHub 发布和评审账号授权仍待仓库地址及发布配置。候选人的个人修改与独立复核情况由候选人补记。

下一步可扩充适用范围已明确、条款明确废止以及关键词容易漏召回的样本，用重复真实运行衡量结果稳定性。
