# AI 使用与贡献

## 候选人贡献

- **选题与验收范围。** 我选择第 3 题「企业知识问答 Agent」，提供通用考核规则、GitHub 交付规范和题目要求，并要求方案逐项覆盖。验收范围包括六项必验场景、两条不同的模型决策路径，以及文档替换后的对照记录。
- **开发顺序。** 我在开工前确认先把 README、需求和技术方案写入项目，再据此实现。开发结束后，我要求对照试卷复核代码、五份指定文档、运行记录和测试是否齐全。
- **交付。** 我提供了最终 GitHub 仓库，并要求核对远程提交。Codex 执行推送与核验，确认远程 SHA 与本地一致、仓库可匿名读取。

## AI 辅助范围与修改

Codex 根据确认后的方案实现 Python CLI、知识库工具、Agent 决策循环和引用校验，编写合成资料、Mock 动作、自动测试及交付文档。真实复跑中，模型曾把仍需确认的制度冲突标为 `answered`。Codex 据此收紧结束条件，有待解决的资料缺口时驳回 `answer`，再将错误交回模型重新选择动作。代码、提示词和测试的修改均由 Codex 执行。

## 验证结果

Codex 执行并保存了 7 组真实模型运行、8 组离线用例和 13 项自动测试的结果。真实模式由 `qwen3.8-flash` 根据工具结果选择动作，离线模式重放事先编写的动作序列。冲突修复前后的记录和资料替换对照均可复核。[测试与评估](03-evaluation.md)
